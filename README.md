# Примеры сайтов (GitHub Pages)

Один репозиторий, много примеров. Главная страница `index.html` показывает карточки из `demos.js`.

## Структура
```
index.html        каталог примеров
demos.js          список примеров (добавляй сюда)
style.css, app.js общий шаблон для barber-classic и education-center
barber-premium/   самостоятельный пример (свой index.html и img/)
barber-classic/   пример на шаблоне (настройки в window.SITE)
education-center/ пример на шаблоне
```

## Как добавить новый пример
1. Создай папку, например `salon-beauty/`, и положи туда `index.html` (и `img/`, если нужны фото).
   Для шаблона: скопируй `barber-classic/`, измени `window.SITE`.
2. Добавь объект в `demos.js` (путь, название, описание, превью).
3. Опубликуй:
```powershell
.\publish.ps1 "добавил пример салона"
```
Сайт обновится через 1–2 минуты.

## Как сделать сайт под клиента
Скопируй папку подходящего примера, поменяй название, цены, контакты, фото и номер WhatsApp (`wa.me/77...`).
Для передачи клиенту выложи его папку отдельно или отдай архивом.

## Примечания
- Все данные в примерах вымышленные. Фото созданы нейросетью.
- Репозиторий публичный: GitHub Pages на бесплатном тарифе требует этого.
